## 1. 로고 원본과 선택 근거

- 새 파일: `assets/logo_1.jpeg`.
- JPEG/JFIF RGB, **314×314, 1:1, 5,195 bytes**, 투명도 없음.
- 실제 내용: 보라색 둥근 사각형 안 흰색/연보라 심볼. 별도 글자는 없습니다.
- 이전 파일: `assets/logo_1.png`, PNG RGBA **2172×724, 3:1, 434,796 bytes**. 대시보드 그림과 ‘AI 노션 빌더’ 문자가 있었습니다.
- 두 이미지를 직접 열어 비교했습니다. 현재 assets의 새 로고 후보는 JPEG 1개였으며 파일명이나 수정 시각만으로 선택하지 않았습니다.
- 이전 PNG는 시작 시 이미 작업 트리에서 제거된 상태여서 Git 부모 커밋의 원본을 임시 위치에 읽어 비교했습니다. 기존 원본·이력을 삭제하거나 덮어쓰지 않았습니다.
- 새 JPEG도 수정하지 않았습니다. 시작·종료 SHA-256:
  `c1f8a47e16a950e0aa55b5ded53818b576a14585f6e940006716ac07dd867d98`

## 2. JPEG 유지 결정

**투명 PNG 변환을 하지 않았습니다.** 보존할 흰 디자인 형상과 JPEG 경계가 있으며 배경 제거 후 원본과 같은 품질인지 확실히 검증할 수 없기 때문입니다. 브라우저 축소 표시도 확인하지 못했습니다.

배경 제거·재압축·업스케일·리사이즈 파일 생성·로고 재생성은 하지 않았습니다. JPEG 원본을 그대로 사용하며 화질이 완벽하다고 선언하지 않습니다.

## 3. 화면별 적용과 크기

로그인·회원가입·교육 설계·매핑·결과·관리자 모두 같은 JPEG를 사용합니다. 5개 HTML에서 각 로고는 1개이며 로그인/회원가입은 같은 화면을 공유합니다.

| 화면 | 데스크톱 | 모바일 |
| --- | --- | --- |
| 로그인·회원가입 | 이미지 64×64 | 480px 이하 56×56 |
| 일반 서비스·관리자 헤더 | 이미지 36×36 / 흰 받침 44×44 | 680px 이하 이미지 32×32 / 받침 40×40 |

원본 전체를 비율대로 표시하며 기존 crop·절대 위치·음수 오프셋·가로 확대 규칙을 제거했습니다. `height:auto`, `object-fit:contain`을 사용합니다.

별도 PPLUS 텍스트는 제거하고 이미지에 `alt="PPLUS"`, `width="314"`, `height="314"`, `decoding="async"`를 적용했습니다. 헤더 로고의 기존 index.html 링크와 접근성 이름은 유지했습니다.

로그인 카드의 흰 배경과 헤더의 흰색 받침으로 JPEG 바깥 모서리가 자연스럽게 연결되도록 설계했습니다. 로그인 로고 아래 간격은 데스크톱 20px·작은 화면 16px입니다. 헤더 높이·UI-003 중앙 카드·입력·관리자 버튼/계정 배치·관리자 본문은 유지했습니다.

고정 로고 슬롯과 대체 텍스트로 로딩 실패의 영향을 제한했습니다. 실제 브라우저의 실패 표시·축소 선명도·흰 테두리 여부는 미검증입니다.

## 4. 경로·빌드 문제 수정

시작 시 HTML과 빌드 allowlist가 이미 사라진 `assets/logo_1.png`를 참조했습니다. 실제 로컬 빌드에서 해당 파일의 ENOENT를 확인했습니다.

현재는 JPEG 경로로 바꿔 빌드가 통과합니다. 공개 allowlist는 이미지 1개만 교체해 **총 30개 유지**입니다. 출력 assets에는 JPEG만 있고 이전 PNG·개발 문서·서버·환경 파일은 포함되지 않습니다.

로컬 서버의 jpg/jpeg MIME을 `image/jpeg`로 추가했습니다. `.png → .jpeg`로 URL도 달라져 이전 PNG URL 캐시를 재사용하지 않습니다. 외부 이미지 호스팅·새 의존성·CDN 설정 변경은 없습니다. 실제 Vercel 배포 후 검증은 하지 않았습니다.
