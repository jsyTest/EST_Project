## 2. 브랜드 표시 복원

UI-004에서는 실제 브랜드 DOM에 JPEG 심볼만 있었습니다. 이제 다음 위치에 PPLUS 텍스트를 한 번씩 추가했습니다.

- 로그인/회원가입: 카드 상단 중앙의 심볼 + PPLUS 그룹.
- 교육 설계·매핑·결과: 헤더 왼쪽의 기존 브랜드 링크 안.
- 관리자: 같은 브랜드 그룹, 기존 서비스 복귀 링크 유지.

그룹 아래의 로그인/회원가입 제목과 기존 안내 1문단은 보존했습니다. 이전 ‘AI 노션 빌더’ 문자는 추가하지 않았습니다.

| 위치 | 심볼 이미지 / 받침 | PPLUS 크기 | 심볼↔글자 간격 |
| --- | --- | --- | --- |
| 로그인/가입 데스크톱 | 64×64 / 64×64 | 28px | 14px |
| 로그인/가입 480px 이하 | 56×56 / 56×56 | 26px | 12px |
| 공통 헤더 데스크톱 | 36×36 / 44×44 | 20px | 10px |
| 공통 헤더 680px 이하 | 32×32 / 40×40 | 20px | 10px |

글자 굵기는 800, 그룹은 수직 중앙 정렬입니다. 로그인 그룹 아래 여백은 기존 20px·작은 화면 16px를 유지했습니다. 424px 카드·모바일 padding·중앙 정렬·짧은 화면 스크롤 구조도 유지했습니다. 표는 CSS 값이며 브라우저 실측값이 아닙니다.

## 3. 접근성·이미지·기존 기능

보이는 PPLUS 문자가 브랜드 이름을 제공하므로 심볼에는 빈 alt와 받침 aria-hidden=true를 적용해 중복 낭독을 피했습니다. 헤더 링크의 href·aria-label은 유지했습니다. 이미지가 실패해도 브랜드 텍스트는 남습니다. 실제 실패 화면은 미검증입니다.

JPEG 원본은 변경하지 않았습니다. 파일은 `assets/logo_1.jpeg`, 314×314이며 SHA-256은 그대로입니다.

`c1f8a47e16a950e0aa55b5ded53818b576a14585f6e940006716ac07dd867d98`

PNG 변환·배경 제거·재생성·재압축은 하지 않았습니다. UI-004의 비율 유지·흰색 받침을 보존했습니다. 실제 흰 배경과 가장자리 품질은 화면에서 확인하지 못했습니다.

헤더 오른쪽 관리자 버튼·이메일·로그아웃, 모바일 계정 줄, 서버 권한 확인 전 버튼 숨김을 유지했습니다. 관리자 카드/메뉴, 인증·저장·planner·매핑·API·Notion 기능 내부는 변경하지 않았습니다.

## 6. 실행 중인 로컬 검토 주소

기존 서버가 **127.0.0.1:8795에서 실행 중**이며 최신 UI-005 빌드의 응답까지 확인했습니다.

- 로그인: http://127.0.0.1:8795/login.html
- 회원가입: http://127.0.0.1:8795/login.html?mode=signup
- 교육 설계/헤더: http://127.0.0.1:8795/index.html
- 매핑/헤더: http://127.0.0.1:8795/mapping.html
- 결과/헤더: http://127.0.0.1:8795/result.html
- 실제 관리자: http://127.0.0.1:8795/admin.html
- 기존 가상 UI 시연: http://127.0.0.1:8795/__demo/admin.html

실제 보호 화면은 본인 계정 로그인이 필요합니다. 가상 시연은 예시 배너·가상 수치를 사용하는 기존 로컬 도구이며 실제 관리자 인증·운영 데이터 검증이 아닙니다. 공개 빌드에 포함되지 않습니다.

관리자 화면에서 대시보드→회원 관리→이용 현황→설정을 선택해 각각 확인할 수 있습니다. 사용자가 네 해상도의 스크린샷을 제공하면 해당 화면과 현재 로컬 파일을 기준으로 피드백을 반영할 수 있도록 서버를 유지했습니다. 아직 스크린샷 피드백을 받거나 반영한 것은 아닙니다.

사용자 확인 항목은 브랜드 중심선/크기, 카드 중앙 위치, 입력 간격, 계정 영역, 관리자 카드 간격, 모바일 스크롤, 흰 모서리, 로딩·오류 시 줄바꿈입니다. 비밀번호·JWT·쿠키는 전달하지 않습니다.
