## 4. 오류 발견 및 증상

**기존 관리자 창에 구 UI가 남아 있다가 강력 새로고침 후 최신 UI로 바뀌는 현상을 관찰했습니다.**

- 처음: 로고 옆 복귀·관리자 자기 링크·사이드바 복귀가 표시됨.
- 일반 새로고침 클릭 후 접근성 트리는 같았음.
- Cmd+Shift+R 후: 오른쪽 복귀 1개, 자기 링크/사이드바 복귀 없음. 이후 관리자 권한 확인 완료.
- 독립 HTTP 읽기에서는 admin.html·auth.js·auth.css·index.html이 당시 로컬 소스와 일치했고, 최신 admin.html에 옛 사이드바 복귀가 없었음.
- 브라우저 캐시/기존 문서 잔존 가능성이 있으나 원인은 미확정. CDN 또는 현재 서버 코드 오류로 단정하지 않음.
- 현재 창에서는 해소됐지만 다른 창/새 배포의 재현성은 미검증. 코드·캐시 정책·배포 설정은 수정하지 않음.

따라서 “오류 없음”으로 일괄 판정하지 않습니다. 재발하면 접속 시각과 일반/강력 새로고침 전후부터 확인하는 후속 진단이 필요합니다.
