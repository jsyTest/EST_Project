# [ChatGPT 전달용] NB-V2-007A 화면 및 폼 분석 오류 수정 결과

## 이전 상태와 이번 범위

EST_Project는 Supabase Auth와 사용자별 설계 저장, V1 Mock 결과, 폼·CSV 매핑, 옵션 색상, 별도 Notion PoC CLI를 갖고 있습니다. NB-V2-007 조사에서 데스크톱 안내문 겹침, 질문 0개 성공 처리, 장문형 오추천, AI 생성 문구의 기대 차이가 발견됐습니다.

이번에는 네 문제만 수정했습니다. 서비스 재설계·새 모듈·CSV 텍스트·실제 Notion 생성·OAuth·관리자 기능은 개발하지 않았습니다.

- 시작 기준은 이전 보고의 06a7c52 이후인 `main / a322899b2519b9ea8afdd4a018ae6b961b27861a`입니다.
- 시작 작업 트리는 깨끗했고 종료 커밋은 동일합니다. 수정 파일은 미커밋 상태입니다.
- 운영 주소는 https://pplus-rouge.vercel.app 이지만 이번 수정은 **로컬 검증 완료·미배포**입니다.

## 수정 전후 차이

| 문제 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 데스크톱 매핑 | 공통 .intro sticky가 편집 행을 가림 | sticky를 .input-page .intro로 한정. 매핑은 일반 흐름, 입력 화면 고정 배치 유지 |
| 질문 0개 | 기본 속성 3개 때문에 검사가 통과 | 분석 실패 표시. 기본 속성만으로 검증/컴파일/CLI 통과 불가 |
| 폼+CSV 중 폼 실패 | CSV가 있으면 실패한 폼을 놓칠 수 있음 | 제공된 폼이 0질문이면 실패를 명시. 폼을 비우면 CSV 단독 재분석 가능 |
| 장문형 신청 동기 | 별칭에 따라 Select | 장문형·서술형·주관식은 Text 우선 |
| 단일/복수 | 별칭과 문구의 우선순위 불명확 | 명시적 Select/Multi-select 우선, 선택지는 임의 생성하지 않음 |
| AI 문구 | AI 설계 생성·재생성 | 설계안 미리보기·미리보기 새로고침, 규칙 기반 샘플과 실제 DB 미생성 설명 |

단답형 성명/이메일/전화의 기존 유용한 유형은 유지했습니다. 명시 유형이 서로 충돌하거나 선택지가 없으면 확인 필요 상태입니다. 번호 없는 문장에서 임의 질문을 만들지 않습니다.

분석 결과는 폼 질문·CSV 컬럼·기본 운영 속성 수를 따로 표시합니다. 실패 시 이전 매핑·컬럼·편집 색상을 보존하되 이전 스키마 다운로드를 무효화합니다. 복원된 원문이 잘못된 경우도 미리보기가 차단됩니다. 수동 속성 추가는 유지합니다.

저장 JSON의 필드/버전이나 DB 구조는 변경하지 않았습니다. 기존 기본 속성 전용 저장값은 편집할 수 있지만 실제 속성을 추가하기 전에는 미리보기를 통과하지 못합니다.

텍스트 페이지 제목은 ‘노션 설계 도우미’로 정리했지만 기존 PNG 로고 안의 ‘AI 노션 빌더’ 브랜드 글자는 남아 있습니다. 이미지와 내부 저장 키는 이번에 교체하지 않았습니다.

## 자동 검사

- 기존 129개 + 신규 회귀 14개 = **143개 통과**, 실패/건너뜀 0.
- V1 Mock 256개 조합은 위 검사에 포함됩니다.
- 새 검사는 0개 입력·기본 전용 모델/CLI 차단, 정상 번호형, 수동 속성/저장 version1 호환, 텍스트·단일·복수 우선, 모호함/선택지 미생성, CSV 단독, 폼 실패 노출·복구, 실패 재분석 값 보존, 잘못된 복원 원문, 다운로드 무효화, 문구/V1 이동을 검증합니다.
- 기존 Auth·저장/복원·색상·CSV·Notion PoC·공개 빌드 검사가 통과했습니다.
- 공개 빌드 24개 성공. 로컬 HEAD 검사에서 공개 24개 200, 내부 CLI/SQL/문서/.env/없는 JS 5개 404입니다.
- 기존 색상/CLI 테스트는 실제 수동 필드 1개를 fixture에 추가했습니다. 검사 사례 삭제는 없습니다.

## 실제 브라우저 검사

기존 로그인 세션이 있는 로컬 Chrome에서 확인했습니다.

- 390·768·960·1280·1440px 매핑 편집: 안내문 가림 재발 없음.
- 번호 없는 가상 폼: 분석 실패와 기본 속성 전용 미리보기 차단 확인.
- 장문형·단일·복수 3문항: Text/Select/Multi-select 표시 확인.
- 색상 분홍 변경·확인·미리보기의 pink 및 새로고침 복원 확인.
- 유효한 가상 CSV+실패한 폼: 폼 실패 노출 확인.
- 폼을 비운 CSV 단독: 0질문/1컬럼/3기본 속성, 확인 후 미리보기 통과.
- V1 입력→결과→수정에서 새 문구와 기존 교육명 유지 확인.
- 저장 패널·계정·로그아웃 버튼 유지 확인.

클라우드 저장이나 로그아웃을 실행하지 않았습니다. 실제 로그인 제출·메일 인증·원격 저장/불러오기는 이번 재검증하지 않았으며 자동 회귀 검사와 구분합니다. 실제 참가자 자료를 사용하지 않았습니다. 물리 모바일/Safari, 긴 CSV/다수 옵션의 전수 화면 검사는 미검증입니다.
