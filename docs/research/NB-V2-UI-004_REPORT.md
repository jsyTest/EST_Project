## 3. JPEG/투명 PNG 결정

**원본 JPEG 유지.** 이미지에는 보존해야 할 흰색 디자인 형상이 있으며 JPEG 가장자리 압축 흔적과 투명 경계가 변환 후 원본과 동일한지 확실하게 검증할 수 없다. 실제 브라우저 축소 표시 검증도 불가능하므로 PNG 변환 품질을 보장하지 않았다.

배경 제거·재압축·업스케일·리사이즈 파일 생성·로고 재생성은 하지 않았다. 투명 PNG를 생성하거나 채택하지 않았다. 원본을 직접 확인한 사실과 작은 화면에서 가장자리 품질을 확인하지 못한 사실을 구분한다. JPEG 자체의 품질도 완벽하다고 선언하지 않는다.

## 5. 접근성·성능·캐시·오류 대비

- 5개 HTML 모두 로고 이미지 1개, alt=PPLUS, width=314·height=314, decoding=async를 지정했다. 로그인과 회원가입은 같은 HTML/스타일을 공유한다.
- 고정 정사각 받침과 원본 크기 속성으로 로딩 전 자리와 비율을 확보했다. 실패 시 대체 텍스트와 슬롯을 남기며 인증/네비게이션을 이미지 로딩에 의존시키지 않는다. 실제 브라우저의 깨진 이미지 표시 방식은 미검증이다.

- 외부 이미지 호스팅·새 npm 패키지·이미지 파생 자산은 추가하지 않았다. 5,195 bytes 원본을 그대로 배포 자원으로 복사한다.
