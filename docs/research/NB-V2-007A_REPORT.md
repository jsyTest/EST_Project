## 4. 질문 0개 처리

- 비어 있는 폼은 CSV 단독 경로에서 정상적인 선택이다. 폼 입력은 있는데 질문 0개라면 `formInputError`가 한국어 오류를 반환한다.
- 폼·CSV 결합 전에 검사하므로 유효한 CSV가 있어도 실패한 폼을 조용히 무시하지 않는다. 폼을 비우고 다시 분석하면 CSV만 사용할 수 있다.
- 질문도 컬럼도 없으면 분석을 실패 처리한다. 기본 운영 속성 3개를 질문으로 세지 않는다.
- `validateModel`/`compileSchema`에서도 사용 중인 질문·CSV·수동 속성이 하나도 없으면 차단한다. 기존 기본 속성 전용 JSON을 CLI로 가져와도 통과하지 않는다.
- 실제 수동 속성 추가는 계속 지원한다. 기존 빈 설계/기본 속성 저장값은 열고 편집할 수 있으며, 유효한 실제 속성을 추가하기 전에는 미리보기를 통과하지 못한다.
- 분석 성공 안내는 ‘폼 질문 N개 · CSV 컬럼 N개 · 기본 운영 속성 N개’로 분리했다.
- 실패 시 기존 모델과 컬럼, 사용자 색상 편집을 보존한다. 이전 스키마 다운로드는 무효화하고 실패 메시지를 보여준다. 입력을 고쳐 재분석해야 한다.
- 저장값을 복원했을 때도 현재 폼 원문이 질문 0개이면 미리보기를 차단한다. DB/저장 JSON 필드나 버전을 추가하지 않았다.
