- 외부 전달: Notion으로 서버 자격 증명(Authorization), API 버전, 고정 부모 ID가 전달된다. Supabase로 정상 사용자 인증 Bearer/공개 연결 키가 전달된다. 폼·CSV·교육생 행·저장 설계 내용은 Notion에 보내지 않는다.
- 코드 경로: 로컬 일회용 구성(아직 없음) → `createTestConnectionHandler` → Supabase Auth/`readTestConfiguration` → `createTestNotionReader.reviewTarget` → 두 고정 GET. 현재 배포 entrypoint는 변경하지 않는다.
- 중단: 사용자/설정 불일치, Bot/Workspace 불일치면 부모 GET 전 중지. 401/403/404/429/5xx/timeout/잘못된 응답/부모 불일치/보관·휴지통·잠금·게시 부적합도 즉시 종료. 자동 재시도·실행 ID 변경·allowlist 자동 갱신 없음. 잠금이 unknown이면 미확인으로 남기고 후속 생성은 금지한다.
- 별개 판정: Bot·Workspace 일치 / 부모 읽기 성공 / 사용자 UI의 공유 범위 확인 / 생성 권한. 앞의 성공으로 뒤를 성공 처리하지 않는다. 생성 권한은 이번 검증에서도 미확인이다.
- 종료/복귀: 한 시도 후 프로세스와 로컬 자격 증명 참조를 정리하고 기본 차단 handler로 복귀한다. 확인을 위해 추가 Notion 요청을 보내지 않는다. 토큰·원격 객체·원격 권한을 삭제/변경하지 않는다.
